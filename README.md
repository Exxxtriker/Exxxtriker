# Leonardo Carvalho

**Desenvolvimento web · Bots para Discord · Integrações**

Olá! Sou o Leonardo, também conhecido como **Exxxtriker**. Desenvolvo projetos de front-end e back-end, com interesse em criar ferramentas para comunidades e experiências interativas.

Meus projetos públicos exploram **JavaScript, Node.js e Discord.js**, combinando comandos, áudio, integrações e persistência de dados.

## Projetos em destaque

### [Gideon the Bard](https://github.com/Exxxtriker/Better-Soundpad-for-Bot-Discord)
Bot para acompanhar mesas de RPG no Discord, reunindo música, soundboard e sistemas de jogo em um só lugar.

- Reprodução de música e efeitos sonoros com controles interativos.
- Rolagem de dados, perfis e economia por servidor.
- Coleção de cartas com inventário, trocas e progressão.
- Persistência com MongoDB e rotinas de validação de comandos.

**Tecnologias:** JavaScript · Node.js · Discord.js · MongoDB · Mongoose

[Explorar o projeto →](https://github.com/Exxxtriker/Better-Soundpad-for-Bot-Discord#readme)

### [Haruka Bot](https://github.com/Exxxtriker/Haruka-bot)
Bot para comunidades no Discord, com ferramentas de moderação, entretenimento e integração com Minecraft.

- Administração de servidores e gerenciamento de mensagens.
- Minigames e recursos de interação com a comunidade.
- Consultas relacionadas ao Minecraft e reprodução de efeitos sonoros.

**Tecnologias:** JavaScript · Node.js · Discord.js · Express · Mongoose · SQLite

[Explorar o projeto →](https://github.com/Exxxtriker/Haruka-bot#readme)
